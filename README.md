# 脉络 Financial Intelligence

面向投研、投资与企业战略团队的**多市场证券数据与事件研究平台**（前端原型）。

以「数据 + 事件」为核心，把分散在财报、公告、股东结构、机构持仓、宏观数据与新闻中的信息，整合为统一的公司数据档案与可追溯的纵向事件 Timeline，帮助用户快速回答三个问题：**发生了什么、影响谁、是否值得行动**。

> ⚠️ 本仓库为**原型演示**：全部数据为模拟数据（Mock Data），不构成任何投资建议。页面内所有价格、财务指标、持仓与事件均已标注来源与「模拟」口径。

## 快速开始

直接用浏览器打开对应文件，或启动本地静态服务器：

```powershell
# 任选其一
cd demo/L02
python -m http.server 8000
# 浏览器访问 http://localhost:8000/mailuo.html
```

## V2 · 跨市场证券数据平台（demo/L02/mailuo.html）

### 首页信息架构

「**国家/地区 → 交易市场 → 板块/行业 → 公司数据库**」逐层浏览，面包屑路径全程可见、可点击返回：

| 国家/地区 | 交易市场 |
| --- | --- |
| 中国大陆 | 上交所主板、科创板、深交所主板、创业板、北交所 |
| 美国 | NYSE、NASDAQ、AMEX |
| 香港 | 港交所主板、GEM |
| 韩国 | KOSPI、KOSDAQ、KONEX |

- 国家卡片：覆盖公司数、交易市场数、当日新增股东/资本变动事件数、代表性市场标签
- 板块页：10 大板块（信息技术/半导体/消费/医疗健康/金融/工业/能源与公用事业/原材料/通信服务/房地产），含覆盖公司数、近 30 日机构净增持公司数、大股东减持事件数、近期重要资本变动事件

### 全局跨市场搜索

- 顶部常驻搜索框，支持**股票代码 / 中文名 / 英文名 / 简称**（如「腾讯」「TSLA」「005930」「北方华创」「ASML」）
- 实时下拉建议 + 市场筛选（全部/中国大陆/美国/香港/韩国），回车直达首个匹配公司

### 公司数据库与数据档案页

当前覆盖 **600+ 家模拟公司**，横跨四大市场，包含锂产业链（赣锋锂业、天齐锂业等）、CPO/光模块（中际旭创、新易盛、Coherent 等）、半导体全产业链、科技、医药、金融、消费等方向；跨市场双重上市公司（如中兴通讯 A/H、阿里巴巴 BABA/9988）按市场分别建档。

公司列表 12 列：代码/名称/国家地区/上市市场/板块/市值/最新价/涨跌幅/机构持仓变化/大股东变化/最近资本事件/披露时间。

公司档案页包含 6 大模块：

1. **事件 Timeline**：纵向时间线，支持按 9 类事件（财报/公告/股东变动/机构持仓/行情异动/新闻/研报/宏观/行业）、重要性（高重要性/已收藏/已标重要）和时间范围（7/30/90 天）筛选
2. **行情与估值**：股价、涨跌幅、市值、52 周高低、PE/PB/PS/股息率/EV/EBITDA/PEG
3. **盈利与财务**：营收/净利润/毛利率/净利率/EPS/ROE/ROA/经营现金流/资产负债率 + 营收净利历史柱状图（原生 SVG）
4. **股东与持仓**：前十大股东及变动、机构持仓、管理层持股、限售/解禁信息
5. **财报与公告**：披露列表，点击标题可定位到 Timeline 对应事件
6. **对比与历史**：同业 PE/PB/ROE/市值横向对比 + 历史趋势

### 交互与研究留痕

- 详情抽屉：完整摘要、来源名称与跳转链接、关联标签、**跳转关联数据模块**（如股东变动事件一键跳到股东与持仓页）
- 收藏（★）、标记重要（⚑，卡片红色描边）、查看来源，均有即时视觉反馈与 Toast 提示
- 5 家核心公司（宁德时代、贵州茅台、特斯拉、腾讯控股、三星电子）为手工精编数据；其余公司由确定性生成器补全，同样覆盖全部模块

## 技术说明

- **零依赖**：无框架、无 npm、无构建步骤，单文件即完整应用
- **图表**：营收/净利柱状图为原生 SVG 生成
- **数据结构**：`COUNTRIES → exchanges → DIRECTORY → COMPANIES / EVENTS` 分层；新增公司仅需在 `SEEDS` 数组追加一行 `[名称, 代码, 交易所, 板块]`，市值/价格/事件等字段由确定性伪随机生成器补全
- **视觉规范**：深蓝 + 石墨灰 + 白主色；低饱和绿（利好/上涨）与低饱和红（风险/下跌）；金额、币种、百分比格式统一；全程标注市场、币种、数据时间与来源

## 明确不做（本期范围）

- 不接真实 API、不做登录/后台/数据库
- 不提供真实时行情、交易下单、荐股或投资建议
- 不做用户协作、评论、消息与付费订阅体系
